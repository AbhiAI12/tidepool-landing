How a lab runs

  1. You write the lab. Instructions, a starting template and the checks that decide pass or fail.
  2. Learners click Launch. A sandbox with scoped credentials appears in about two minutes.
  3. Checks run on demand. Each task shows pass or fail with a reason.
  4. The sandbox is deleted. At the time limit or spending cap, whichever comes first.

Questions we hear most

Do learners need their own cloud account?

No. Each learner gets a temporary sandbox with scoped credentials. It is deleted when the lab ends.

How are labs checked?

Validation scripts inspect the real environment, for example whether a storage account exists with public access off, and report pass or fail per task.

What happens if a learner forgets to stop a lab?

Every lab has a time limit and a spending cap. Resources are removed automatically when either is reached.
